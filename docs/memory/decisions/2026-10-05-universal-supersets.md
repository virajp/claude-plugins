## What was decided before

The gate configs and the hygiene files carried a base, and each pack asked for
its additions through its `tool-config:` list — a dprint plugin, an exclude
through `all add-exclude`, a linter ignore, a hook, a `.gitignore` template
fetched from github/gitignore and pinned by SHA, an attribute line — written
into that pack's own block and removed with it.

## What changed

The user, verbatim: *"If there's a pack that might need to add entry then simply
add them whether or not the pack is installed"*. Confirmed with the other nine
reversals on 2026-10-05: *"yes, confirm all ten"*.

- **S1 — `.gitignore`** is a curated list in banner sections grouped by stack —
  node, python, dart and flutter, swift and xcode, secrets (incl.
  `fnox.local.toml`), the mise locals (`mise.local.toml`, `mise.*.local.toml`,
  `**/mise.local.lock`), `graphify-out/` — never an upstream template.
- **S2 — `.gitattributes`** carries the base plus `pnpm-lock.yaml` and
  `Package.resolved` as `linguist-generated`.
- **S3 — the exclusion set** — dprint (each path as the `../X` + `**/X` pair,
  `includes: ["../**"]`), taplo, the pre-commit global `exclude` and the linter
  ignores — carries every pack's exclude; the gitleaks allowlist stays the
  generated subset.
- **S4 — dprint** carries every plugin: dockerfile, malva, markup_fmt and
  typescript beside the base's.
- **S5 — no pack adds a line** to any universal file. A pattern for a tree the
  repo never produces matches nothing; a plugin whose extensions it lacks costs
  one download.

## Rulings during execution

- **W7** — `linter.yaml` is generated by the installer only when absent, so it
  ships as a static asset, and the checker's exclusion-set rule does not hold
  its `ignores` equal to the other lists.

## The alternatives rejected

- **Vendored upstream gitignore templates** — a network call on every render,
  and a block that silently never lands when it fails.
- **Per-pack additions** — every addition needed a block, a removal path and a
  checker rule for its grammar.
