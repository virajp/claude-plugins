Four phases, in order.

Everything up to the blueprint is done in full before planning. Each phase is a slash command, and each one asks you one question at a time.

/vwf:product

Product

Pin the outcome contract: the problem, the users, measurable goals, and the order to build in. Everything downstream traces to it.

/vwf:blueprint

Blueprint

Keep an always-current blueprint of the whole product, organized by flow, closed by a whole-product coherence review.

/vwf:plan

Plan

Diff the blueprint against the real code for one slice, plan its unbuilt dependencies first, and write the delta to apply.

/vwf:execute

Execute

Implement the plan unattended under strict TDD, with code, security, acceptance and UX review, behind one merge gate.

Install

One command registers the marketplace and installs the workflow. stackgen, its one dependency, comes with it.

copypnpx @virajp.dev/claude-plugins --all

That is a thin wrapper over Claude Code's own two commands, which work just as well directly.

# Register this repo as a plugin marketplace, once claude plugin marketplace add virajp/claude-plugins # Install the workflow claude plugin install vwf@virajp-plugins

Restart Claude Code afterwards, then run /vwf:doctor. Nothing is checked at install time.

Know this before you install.

vwf is deliberately heavyweight. Some of what it needs is a real adoption blocker rather than a preference.

MODEL AND COST
  • Built for the 1-million-token context window. The orchestrator holds the blueprint, the plan, the registry and each subagent's output at once. The standard window will degrade or overflow on a real cycle.
  • Runs opus where judgment decides the outcome. An execute cycle runs several opus subagents per step with fix loop-backs. Expect a meaningful token cost per slice.
DEPENDENCIES AND SHAPE
  • Expects a testable, registry-described project. Execute enforces TDD and a coverage gate. It will not operate on an ad-hoc folder.
  • Five binaries must be on your PATH: mise, graphify, uv, pnpm and rtk. Nothing checks this at install time, and doctor does not cover all five.
  • Opinionated on purpose. One workflow, one set of conventions, sized for a solo developer or a small team.
