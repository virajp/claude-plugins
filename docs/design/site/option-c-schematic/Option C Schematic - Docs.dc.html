vwf plugin

The flagship plugin of the marketplace. An opinionated workflow that turns a vague idea into a shipped, reviewed product through four disciplined phases: Product, Blueprint, Plan, Execute, with post-deploy verification and a production-feedback intake closing the loop.

The four phases, and the loop that closes them.

This page is the reference, command by command. If you would rather follow one product's whole walk through the workflow, the journey-shaped guides are in Guides, organized by the situation you are in.

Install

shcopy
# Once claude plugin marketplace add virajp/claude-plugins # Installs vwf and its one dependency, stackgen claude plugin install vwf@virajp-plugins

Add --scope project to either command to keep it to one repo. Restart the agent afterwards, then run /vwf:doctor. Nothing is verified at install time, and doctor is what reports a missing required binary.

Prerequisites

vwf shells out to a few external tools. Install them first. Nothing checks them at install time, and the table gives the command for each.

ToolRequiredWhyInstall
miserequiredtask runner, resolves the toolchainbrew install mise
graphifyrequiredknowledge graph the commands rely onmise use -g pipx:graphifyy@latest
node + pnpmrequiredruns the Context7 MCP servermise use -g node@latest pnpm@latest
Claude Code CLIrequiredhosts the commandsmise use -g claude-code@latest
uvrequiredgraphify's Python runtimemise use -g uv@latest
rtkrecommendedthe token-saving Bash hookbrew install --formulae rtk
Nothing checks these at install time. claude plugin install vwf succeeds regardless, so the first thing to run afterwards is /vwf:doctor. It reports a missing required tool as a blocking finding, and both /vwf:setup and /vwf:execute halt on one.

Caveats

vwf is deliberately heavyweight. Know what you are signing up for before adopting it.

Built for a large context window. The orchestrator holds a lot at once: the blueprint, the plan, the registry, and each subagent's output. Run Claude Code with the 1-million-token context; the standard window will degrade or overflow on a real cycle.
