# Runbook (draft)

Does or guides an operational procedure on live systems, where a wrong step has
a blast radius.

| Section       | Holds                                          |
| ------------- | ---------------------------------------------- |
| Blast radius  | What breaks if a step goes wrong, and for whom |
| Preflight     | Read-only checks that must pass first          |
| Decision tree | Table: observation → branch                    |
| Steps         | Numbered. Mark and confirm each mutating step  |
| Rollback      | Per step, and tested                           |
| Verify        | The signals that prove success                 |

Detail this template at the first real runbook.
