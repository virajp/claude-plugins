# Jetpack Compose — Room

**Wiring, configuration and anti-patterns only.** DAO query syntax, type
converters and the full API are Context7's at use time.

Room is the app's local database and its offline source of truth. Its code is
generated by KSP and its schema is exported and committed.

## Setup order

1. **Catalog entries** for Room's runtime, its compiler, its Gradle plugin and
   its testing artifact; the compiler is a `ksp(...)` dependency.
2. **Apply the Room Gradle plugin and set the schema directory** —
   `room { schemaDirectory("$projectDir/schemas") }` — in the module that
   declares the database. `exportSchema` stays on; the exported JSON under
   `schemas/` is committed with each version.
3. **One `@Database` class** in the data layer, listing its entities and the
   current `version`, built once by a Hilt `@Provides @Singleton` function.
4. **DAOs return `Flow` for observed queries** and are `suspend` for one-shot
   reads and writes; Room runs them off the main thread.
5. **Repositories wrap DAOs**; nothing above the data layer imports a DAO or an
   entity.

## Schema changes

- **Every change bumps `version` and ships a migration.** Prefer
  `@AutoMigration(from, to)` for additive changes, with an `AutoMigrationSpec`
  for renames and deletes; write a manual `Migration` only where an automatic
  one cannot express it.
- **Every migration is tested** with `MigrationTestHelper` against the exported
  schemas: create the old version, insert data, migrate, and assert the data
  survived.
- **`fallbackToDestructiveMigration` is never set** on a database holding the
  user's data. A cache that may be rebuilt says so in a comment beside it.

## Structure

- **Entities are not the app's model.** Map entities to model types in the
  repository, so a column change does not ripple into the UI.
- **Transactions** wrap multi-table writes (`@Transaction` or
  `withTransaction`), so a sync never leaves half its writes.
- **Large result sets** are paged through [Paging](paging.md), with Room's
  `PagingSource`.

## Testing

DAO tests run on the JVM under Robolectric against
`Room.inMemoryDatabaseBuilder`, closed after each test.

## Anti-patterns

| Anti-pattern                                | Instead                                        |
| ------------------------------------------- | ---------------------------------------------- |
| `allowMainThreadQueries()`                  | `suspend` DAOs and `Flow`                      |
| Destructive migration on user data          | a tested migration                             |
| Schema JSON gitignored                      | commit `schemas/`; migrations are tested against it |
| Entities in UI state                        | model types mapped in the repository           |
| A Room table for a few settings             | [DataStore](datastore.md)                      |
