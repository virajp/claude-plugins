# Keeping docs current

- Update docs when you change a public API, add a module, or change behavior.
- Update the CHANGELOG when you bump a version.
- Add no documentation stub. Write the doc, or do not create the file.

## CHANGELOGs

- Write one `## vMAJOR.MINOR.PATCH` heading per version.
- Write no "Unreleased" section. Always commit under a version heading.
- Match entries to conventional-commit types: `feat`, `fix`, `refactor`.
