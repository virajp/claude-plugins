# brag plan — vwf

**What:** vwf, a Claude Code plugin that takes a vague idea to a reviewed
release in four phases: Product, Blueprint, Plan, Execute. **For:** builders on
Claude Code who want discipline, not vibes. **Different:** it asks one question
at a time while authoring, then builds unattended, and never merges until you
approve. **Visual hook:** the site's own construction drawing of the mark,
drawing itself on the blue dot-grid sheet. **Tone:** polished, in the site's
blueprint idiom: dark ink, one blue, radius 0, Schibsted Grotesk + Geist Mono.
Tight soft fades, dimension-rule wipes. **Share caption:** Four phases from a
vague idea to a reviewed release.
